# 电商运营数据分析 Agent

用自然语言提问，自动查询销售数据并给出结论与图表的运营分析助手。

## 功能特点

- 自然语言提问：支持"上个月""9 月"这类口语化表达，自动换算成日期区间
- 工具调用：模型自主决定调用哪个分析函数，不靠猜
- 数据分析：总销售额、销售额排名、滞销商品识别
- 可视化：排名结果自动生成柱状图
- 不编造：查不到数据时如实说明，不虚构数字

## 技术栈

Python / pandas / DeepSeek 对话模型 / Function Calling / Streamlit

## 工作原理

1. 用户用自然语言提问
2. 模型根据提示词里的当前日期，把"上个月"换算成具体日期区间
3. 模型从工具清单中选合适的分析函数，并填入参数
4. 代码执行函数，用 pandas 完成筛选、分组、排序
5. 结果回传给模型，模型整理成结论并附上洞察
6. 排名类结果同时交给界面，用柱状图呈现

## 项目文件说明

- `make_data.py`：生成模拟销售数据
- `analysis.py`：三个分析函数（总销售额、畅销排名、滞销识别）
- `agent.py`：命令行版 Agent
- `app.py`：网页版界面（含柱状图）
- `orders.csv`：模拟销售数据

## 如何运行

1. 安装依赖：`pip install openai streamlit pandas python-dotenv`
2. 在 `.env` 里填写 DeepSeek 的 API 密钥
3. 运行：`streamlit run app.py`

## 效果示例

- 用户：上个月销售额最高的三个商品是哪些？
  → Agent：调用 top_products，返回排名表和柱状图，并指出第一名比第二名高出约 59%
